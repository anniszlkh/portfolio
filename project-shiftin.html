01 / PROJECT OVERVIEW

Creating a digital brand experience.

Shiftin is an interior design and fit-out brand with the tagline "We Design Transition".

The website was designed to introduce the brand, communicate its services and showcase its projects through a clean and structured digital experience.

The overall direction focuses on simplicity, visual consistency and an organised presentation of content.

PROJECT Shiftin Corporate Website
MY ROLE Website Design & Development
TYPE Corporate Website
LOCATION Petaling Jaya, Malaysia

02 / THE OBJECTIVE

Giving the brand a digital identity.

The Challenge

A corporate website needs to communicate a brand's identity clearly while making information easy for visitors to explore.

The challenge was to organise the brand's information, services and project portfolio into a cohesive website without making the interface feel crowded.

The Objective

To develop a professional, responsive website that presents Shiftin's identity, highlights its services and provides visitors with a clear way to explore the company's work.

05 / DEVELOPMENT

From design concept to working website.

The website was developed using standard frontend web technologies, with a focus on responsive layouts and reusable page components.

Frontend Development

HTML was used to structure the content, CSS to define the layout and visual appearance, and JavaScript to support interactive elements.

Responsive Design

Responsive layouts were considered across different screen sizes to provide a consistent browsing experience on desktop, tablet and mobile devices.

Page Organisation

Separate pages were organised for the main website sections, allowing visitors to navigate the brand's content more easily.

07 / KEY TAKEAWAYS

What I learned from this project.

Working on the Shiftin website helped me understand how visual design and frontend development work together to create a consistent digital experience.

It also strengthened my understanding of page structure, responsive layouts, typography, colour consistency and content organisation.

Most importantly, the project reinforced the importance of designing with both the brand identity and the website visitor in mind.
