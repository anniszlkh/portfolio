01 / PROJECT OVERVIEW

Building a smarter mobile attendance experience.

AtTrack is a mobile attendance application designed to simplify employee attendance tracking a through mobile technology.

The mobile application was developed to allow employees to record their attendance, track their attendance history and stay connected through real-time notifications. It also incorporates background location tracking to support attendance monitoring and verification.

The overall direction focuses on accessibility, convenience and reliable attendance tracking, providing employees and administrators with a more efficient way to manage daily attendance activities.

PROJECT Senhon Attendance Management Mobile Application
MY ROLE Mobile Application
TYPE Corporate Internal System
LOCATION Alor Setar, Malaysia

02 / THE OBJECTIVE

Connecting mobile attendance tracking with centralised web management.

The Challenge

Managing employee attendance across different platforms requires a reliable way to synchronise attendance records, employee information and daily activities.

The challenge was to develop a mobile application that could communicate seamlessly with a web-based attendance management system, ensuring that attendance data recorded by employees could be accessed and managed centrally by administrators.

The Objective

To develop an integrated attendance management system consisting of a Flutter-based mobile application and a web dashboard, connected through PHP REST APIs and a shared MySQL database.

05 / DEVELOPMENT

From concept to a connected mobile attendance application.

The AtTrack mobile application was developed using Flutter to provide employees with a convenient way to manage their daily attendance. The application integrates with the web-based attendance management system through PHP APIs, allowing attendance data to be shared and synchronised across both platforms.

Mobile App Development

Flutter and Dart were used to develop the mobile application, including the user interface, navigation, attendance functions and user account features.

API Design

PHP REST APIs were integrated to connect the mobile application with the web dashboard and shared MySQL database. This enables attendance records, employee information and approval updates to be exchanged between both platforms.

Background Location Tracking

Background location tracking was implemented to support employee attendance monitoring, allowing location-related data to be collected as part of the attendance tracking process.

Push Notifications

Push Notifications Firebase Cloud Messaging (FCM) was integrated to deliver attendance-related notifications, keeping employees informed about important updates and attendance approval statuses.

07 / KEY TAKEAWAYS

What I learned from this project.

Developing the AtTrack mobile application helped me understand how mobile app development, backend programming and database management work together to build an integrated attendance management system.

It strengthened my knowledge of Flutter, Dart, PHP REST API integration, MySQL database connectivity and Firebase Cloud Messaging, while improving my understanding of data synchronisation between mobile and web platforms.

Most importantly, this project taught me the importance of developing applications that are not only functional but also reliable, user-friendly and capable of handling real-world requirements, particularly in background location tracking and cross-platform data management.
