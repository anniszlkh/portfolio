01 / PROJECT OVERVIEW

Managing finances through a smarter cashbook experience.

Cashbook is a web-based financial management system designed to simplify business bookkeeping and daily transaction recording.

The system was developed to provide a centralised platform for recording income and expenses, managing financial transactions and monitoring business cash flow through a clean and structured interface.

The overall direction focuses on financial organisation, accurate record-keeping and efficient transaction management, creating a seamless experience for managing everyday business finances.

PROJECT Senhon Financing Management Website
MY ROLE Website Design & Development
TYPE Corporate Finance
LOCATION Alor Setar, Malaysia

02 / THE OBJECTIVE

Bringing financial records into one digital platform.

The Challenge

Managing business finances requires an organised system to keep track of daily income, expenses, transaction records and overall cash flow.

The challenge was to create a centralised cashbook system that simplifies financial record-keeping and transaction management while keeping the interface clean, intuitive and easy to navigate.

The Objective

To develop a user-friendly cashbook management system that allows users to record income and expenses, manage financial transactions and monitor business cash flow efficiently through a structured web interface.

05 / DEVELOPMENT

From concept to a functional cashbook system.

The Cashbook web application was developed to centralise financial records and daily business transactions into one management platform, with a focus on functionality, data organisation and ease of use.

Frontend Development

HTML was used to structure the content, CSS to define the layout and visual appearance, and JavaScript to support interactive elements.

Responsive Design

Responsive layouts were considered across different screen sizes to provide a consistent browsing experience on desktop, tablet and mobile devices.

Page Organisation

Separate pages were organised for the main website sections, allowing visitors to navigate the brand's content more easily.

07 / KEY TAKEAWAYS

What I learned from this project.

Developing the Cashbook web application helped me understand how frontend development, backend programming and database management work together to build a functional financial management system.

It strengthened my knowledge of HTML, CSS, JavaScript, PHP, MySQL, data organisation and CRUD operations, while improving my ability to manage financial records and structure interfaces for everyday bookkeeping tasks.

Most importantly, this project taught me the importance of building systems that are not only functional but also user-friendly, reliable and efficient in managing real-world financial data.
