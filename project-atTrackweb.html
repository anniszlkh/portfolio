01 / PROJECT OVERVIEW

Building a smarter attendance management experience.

AtTrack is an attendance management system designed to simplify employee attendance tracking and administrative workflows.

The web dashboard was developed to provide a centralised platform for managing employee records, monitoring attendance activities and reviewing attendance reports through a clean and structured interface.

The overall direction focuses on usability, data organisation and efficient attendance management, creating a seamless experience for both administrators and employees.

PROJECT Senhon Attendance Management Website
MY ROLE Website Design & Development
TYPE Corporate Internal System
LOCATION Alor Setar, Malaysia

02 / THE OBJECTIVE

Bringing attendance data into one digital platform.

The Challenge

Managing employee attendance requires an organised system to keep track of attendance records, employee information and daily activities.

The challenge was to create a centralised dashboard that simplifies attendance monitoring and data management while keeping the interface clean, intuitive and easy to navigate.

The Objective

To develop a user-friendly attendance management dashboard that allows administrators to monitor employee attendance, manage employee records and review attendance history efficiently through a structured web interface.

05 / DEVELOPMENT

From concept to a functional attendance system.

The AtTrack web dashboard was developed to centralise employee information and attendance records into one management platform, with a focus on functionality, data organisation and ease of use.

Frontend Development

HTML was used to structure the content, CSS to define the layout and visual appearance, and JavaScript to support interactive elements.

Responsive Design

Responsive layouts were considered across different screen sizes to provide a consistent browsing experience on desktop, tablet and mobile devices.

Page Organisation

Separate pages were organised for the main website sections, allowing visitors to navigate the brand's content more easily.

07 / KEY TAKEAWAYS

What I learned from this project.

Developing the AtTrack web dashboard helped me understand how frontend development, backend programming and database management work together to build a functional web-based system.

It strengthened my knowledge of PHP, MySQL, user authentication, data organisation and CRUD operations, while improving my ability to structure interfaces for administrative tasks.

Most importantly, this project taught me the importance of building systems that are not only functional but also user-friendly, reliable and efficient in managing real-world data.
