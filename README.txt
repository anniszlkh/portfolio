ANIS — PERSONAL PORTFOLIO
========================

1. Open index.html in a browser to preview.
2. Edit css/style.css for styling.
3. Edit js/script.js for interactions.
4. Replace hello@example.com and your.email@example.com with your real email.
5. Replace the # links on GitHub and LinkedIn with your profile URLs.
6. Review all project descriptions and update your exact role, contribution, dates,
   screenshots and live/repository links before publishing.
7. Add your own images under assets/images if you want to replace the CSS mockups.

This is a static HTML/CSS/JavaScript website. No build tools are required.
